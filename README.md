# Customer Retention Analysis

## Project Overview
This project analyzes customer purchasing behavior using Python.

## Objectives
- Identify repeat customers.
- Identify one-time customers.
- Calculate the customer retention rate.
- Visualize customer data using charts.

## Tools Used
- Python
- Pandas
- Matplotlib

## Dataset
Brazilian E-Commerce Public Dataset by Olist (Kaggle)

## Visualizations
- Customer Retention Pie Chart
- Repeat vs One-Time Customers Bar Chart

## How to Run
1. Install the required libraries:
   pip install pandas matplotlib
2. Keep both CSV files in the project folder.
3. Run:
   python main.py
